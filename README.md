# MITRE ATT&CK Threat Mapping

A hands-on portfolio of MITRE ATT&CK threat mapping and SOC analysis exercises.

## About

This repository documents practical exercises focused on:

- Analyzing cybersecurity incident scenarios
- Extracting attacker behaviors from evidence
- Mapping behaviors to MITRE ATT&CK tactics and techniques
- Practicing evidence-based threat analysis
- Documenting uncertainty when available evidence is insufficient
